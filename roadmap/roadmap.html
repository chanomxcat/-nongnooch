การกลับมาเที่ยวซ้ำ

รวบรวมข้อมูลนักท่องเที่ยวผ่านการสมัครสมาชิกกับสวนนงนุช สมาชิกได้รับพ้อยและโปรโมชันเมื่อกลับมาใช้บริการอีก

ทำไมต้องมี Agent

นักท่องเที่ยวต่างชาติส่วนใหญ่ซื้อบัตรผ่าน Agent นงนุชจึงเข้าไม่ถึงข้อมูลของกลุ่มนี้ โครงการจึงให้ไกด์ของ Agent ชวนนักท่องเที่ยวสมัครสมาชิกด้วย Invite code และได้พ้อยตอบแทน

  • ฐานสมาชิกของนงนุชเอง

    นักท่องเที่ยวทุกกลุ่ม (ออนไลน์ เคาน์เตอร์ และผ่าน Agent) สมัครสมาชิกและให้ความยินยอมรับข่าวสาร

  • การกลับมาเที่ยวซ้ำ

    สมาชิกสะสมพ้อยและได้โปรโมชันเมื่อกลับมา (เปิดแลกพ้อยในเฟส 2)

  • Agent เป็นพันธมิตรหาสมาชิก

    ไกด์ได้พ้อยเมื่อนักท่องเที่ยวสมัครด้วย Invite code ของตน

  • ขายผ่านดิจิทัลมากขึ้น

    ขายบัตร บัตรห้องอาหาร และการแสดง ผ่าน Website และ App

  • Sponsor และ Partner

    รายได้ใหม่ที่นงนุชอนุมัติทุกรายการก่อนเผยแพร่ (เฟส 3 ถึง 4)

2

เงินเข้านงนุชโดยตรง

ทุกการชำระเงินเข้าบัญชี Merchant ของนงนุช WV ไม่รับเงินแทน
