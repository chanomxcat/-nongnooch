# Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** บริษัททัวร์สมัครบัญชีพร้อมอัปโหลดหนังสือรับรองไป Object Storage และรอทีมนงนุชอนุมัติ ไกด์เข้าร่วมบริษัทด้วยลิงก์เชิญหรือขอเข้าร่วม แล้วได้ Invite code + QR ส่วนตัว ระบบสร้าง Referral เมื่อมีผู้สมัครด้วยโค้ด ติดธงรูปแบบผิดปกติ และแสดงยอดรายไกด์ / บริษัทเป็นจำนวนเท่านั้น

**Architecture:** service `agent` (schema `agent`) บน chassis ของ Plan 01 · HTTP ผ่าน gateway `/api/agent/...` อ่านตัวตนด้วย `authn.From(ctx)` (บริษัทและไกด์ล็อกอินด้วย OTP เบอร์ `typ=user`, ทีมนงนุชเป็น `typ=staff` role `agent_manager`) · เอกสารเก็บใน MinIO ผ่าน interface `DocStore` · gRPC `AgentService.ValidateInvite` ที่ `agent:9090` ให้ Member เรียกตอนสมัคร · consumer `member.registered` และ `member.invite_added` → Referral + ธง → outbox `referral.created` · consumer `points.changed` (ใช้ `guideId`) เก็บยอดพ้อยรายไกด์ไว้แสดง dashboard · consumer `account.deleted` ระงับไกด์ / ลบข้อมูลใน referral

**Tech Stack:** Go 1.23 + chassis (Plan 01), `github.com/minio/minio-go/v7`, `github.com/skip2/go-qrcode`, `google.golang.org/grpc`, `pkg/thaiid` (Plan 03 Task 1)

**Spec:** [docs/system-design.md](../../system-design.md) F2, S1 ขั้น 21–23, 36–43, หัวข้อ 1.2 (Agent), Q6 · [ROADMAP](../../../roadmap/ROADMAP.md) E10, หัวข้อ 12 PDPA · [contracts](2026-11-11-contracts.md) · ขึ้นกับ [Plan 01](2026-11-11-01-platform-chassis.md), [Plan 03](2026-11-11-03-member-point.md) (gRPC `GetContactPrefs`, seed, ตัดพ้อย), Plan 12 Task 1 (`authn`)

- **ไกด์ต้องเป็นสมาชิกก่อน** (`X-Member-Id` ไม่ว่าง, contracts §3) เพราะพ้อยไกด์ลงบัญชีสมาชิกของไกด์ โดย Member ใช้ `guideMemberId` ใน `referral.created` ตรง ๆ (Plan 03 Task 4) และ `ValidateInvite` คืน `guide_member_id`

  - `func (s *AgentService) RegisterCompany(ctx context.Context, in CompanyInput) (Company, error)` — ตรวจ → ดมชนิดไฟล์ 512 byte แรกด้วย `http.DetectContentType` (`application/pdf`, `image/jpeg`, `image/png`) → `Put` ทุกไฟล์ที่ key `companies/{companyId}/{docId}` → `BEGIN` insert company (`status=pending`) + documents `COMMIT` · DB ล้ม → `Delete` ไฟล์ที่ใส่ไปแล้ว · error `ErrInvalidTaxID`, `ErrCertRequired`, `ErrFileTooLarge`, `ErrFileType`, `ErrCompanyExists`
  - HTTP: `POST /companies` (`authn.Require("user")`, multipart: `name, taxId, tatLicense?, contactName, contactEmail`, ไฟล์ `companyCert` บังคับ, `tatLicenseFile?`) ใช้ `X-User-Sub` เป็น `contactPhone` (ยืนยัน OTP แล้วจาก Plan 02) และ `X-Lang` เป็น `lang` ได้ `201 Company` · `400 invalid_tax_id|cert_required`, `413 file_too_large`, `415 file_type`, `409 company_exists` · `GET /companies/me` ได้ `200 Company` (`{companyId, name, taxId, status, rejectReason?, createdAt}`)
  - บริษัทที่ `rejected` ส่ง `POST /companies` ซ้ำด้วยเบอร์เดิมได้ (แถวเดิมกลับเป็น `pending` + เอกสารชุดใหม่)

```sql
CREATE TABLE companies (
  id CHAR(36) PRIMARY KEY, name VARCHAR(200) NOT NULL, tax_id CHAR(13) NOT NULL UNIQUE, tat_license VARCHAR(32) NULL,
  contact_name VARCHAR(100) NOT NULL, contact_phone VARCHAR(20) NOT NULL UNIQUE, contact_email VARCHAR(254) NOT NULL,
  lang CHAR(2) NOT NULL, status VARCHAR(10) NOT NULL, -- pending|approved|rejected|suspended
  reject_reason VARCHAR(500) NULL, join_token CHAR(22) NULL UNIQUE,
  reviewed_by VARCHAR(64) NULL, reviewed_at DATETIME(6) NULL, created_at DATETIME(6) NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
CREATE TABLE company_documents (
  id CHAR(36) PRIMARY KEY, company_id CHAR(36) NOT NULL, kind VARCHAR(16) NOT NULL, object_key VARCHAR(200) NOT NULL,
  content_type VARCHAR(32) NOT NULL, size_bytes INT NOT NULL, sha256 BINARY(32) NOT NULL, created_at DATETIME(6) NOT NULL,
  INDEX idx_company (company_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
CREATE TABLE guides (
  id CHAR(36) PRIMARY KEY, company_id CHAR(36) NOT NULL, member_id CHAR(36) NOT NULL UNIQUE, phone VARCHAR(20) NOT NULL UNIQUE,
  name VARCHAR(100) NOT NULL, lang CHAR(2) NOT NULL, status VARCHAR(10) NOT NULL, -- pending|active|rejected|suspended
  joined_via VARCHAR(8) NOT NULL, created_at DATETIME(6) NOT NULL, updated_at DATETIME(6) NOT NULL, INDEX idx_company (company_id, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
CREATE TABLE invite_codes (code VARCHAR(32) PRIMARY KEY, guide_id CHAR(36) NOT NULL UNIQUE, created_at DATETIME(6) NOT NULL) ENGINE=InnoDB;
CREATE TABLE referrals (
  id CHAR(36) PRIMARY KEY, member_id CHAR(36) NOT NULL UNIQUE, guide_id CHAR(36) NOT NULL, company_id CHAR(36) NOT NULL,
  invite_code VARCHAR(32) NOT NULL, ip VARBINARY(16) NULL, device_id VARCHAR(64) NULL, phone_num BIGINT NULL, -- ใช้ตรวจเบอร์เรียงกันเท่านั้น ห้ามส่งออก
  flags JSON NOT NULL, created_at DATETIME(6) NOT NULL,
  INDEX idx_guide_time (guide_id, created_at), INDEX idx_ip_time (ip, created_at), INDEX idx_device_time (device_id, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
CREATE TABLE guide_points (guide_id CHAR(36) PRIMARY KEY, pending_points INT NOT NULL, cut_points INT NOT NULL, updated_at DATETIME(6) NOT NULL) ENGINE=InnoDB;
CREATE TABLE referral_reviews (referral_id CHAR(36) PRIMARY KEY, decision VARCHAR(4) NOT NULL, reason VARCHAR(500) NULL, staff_id VARCHAR(64) NOT NULL, created_at DATETIME(6) NOT NULL) ENGINE=InnoDB;
CREATE TABLE audit_log (id CHAR(36) PRIMARY KEY, actor VARCHAR(64) NOT NULL, action VARCHAR(32) NOT NULL, target VARCHAR(64) NOT NULL, detail JSON NULL, created_at DATETIME(6) NOT NULL) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
