- ทำตามแผน implementation ครบทุก step และ test ที่เกี่ยวข้องผ่าน (`make test`, `make test-int`)

- ทำตาม Global Constraints ของ system design (1 schema ต่อ service, outbox, consumer idempotent, 7 ภาษา)
