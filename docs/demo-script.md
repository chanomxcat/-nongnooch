## 1. ก่อนเริ่ม (เตรียมก่อน demo อย่างน้อย 30 นาที)

**ต้องมี**
- Docker Desktop เปิดอยู่ (สถานะ Engine running) · RAM ว่างประมาณ 8 GB
- เบราว์เซอร์ Chrome / Edge (โหมดปกติ ไม่ต้อง incognito)
- เปิด terminal ที่โฟลเดอร์ `C:\Claude Code\nongnooch` (Git Bash)

**เริ่มระบบจากศูนย์ (ล้างข้อมูลเดิมทั้งหมด)**

```bash
make demo-reset CONFIRM=yes
```

- ใช้เวลา: ประมาณ **1–3 นาที** ถ้า image build ไว้แล้ว (วัดจริง 143 วินาที) · ประมาณ **5 นาที** ถ้า build ใหม่ทั้งหมด (วัดจริง 296 วินาที) · ครั้งแรกบนเครื่องใหม่ต้องดาวน์โหลด image เพิ่ม (หลาย GB) ให้ทำล่วงหน้า
- จบแล้วต้องเห็นบรรทัด
  `[seed] today: orders=12 sales=฿18600 tickets=30 scans=8 newMembers=6`
- ข้อมูลจำลอง "วันนี้" ผูกกับวันที่ที่รันคำสั่ง ให้รัน **เช้าวัน demo** (ไม่ใช่คืนก่อน)

**เช็กก่อนขึ้นจอ (1 นาที)**
1. เปิด http://localhost:3000/th → หน้าแรกขึ้น
2. เปิด http://localhost:8090 → หน้า mockext console ขึ้น
3. เปิด http://localhost:3001 → login `admin@demo.nongnooch.local` / `Demo1234!` → หน้า Dashboard มีตัวเลข

**เปิดแท็บรอไว้ตามลำดับ:** (1) เว็บ http://localhost:3000/th (2) console http://localhost:8090 (3) admin http://localhost:3001

## 5. สิ่งที่เป็นข้อมูลจำลอง

- **การจ่ายเงิน** เป็น KBank จำลอง (ไม่มีเงินจริง ไม่ตัดบัตรจริง) และ **SMS/OTP** แสดงใน mockext console แทนการส่งเข้ามือถือ
- Turnstile (กันบอท) เป็นช่องติ๊กจำลอง
- **ราคาบัตร** (ไทย ฿300 / ต่างชาติ ฿600 / เด็ก ฿150–300 / รายปี ฿1,500–3,000) เป็นราคาตัวอย่าง ไม่ใช่ราคาจริง
- ออเดอร์ 12 รายการ, บัตร 30 ใบ, สแกน 8 ครั้ง และสมาชิกตัวอย่าง สร้างโดยสคริปต์ seed เพื่อให้ dashboard มีตัวเลข
- รูปภาพบนเว็บเป็นภาพประกอบจาก Figma ยังไม่ใช่ภาพถ่ายจริงของสวน
- ปุ่ม "คัดลอกรหัส QR (เดโม)" มีเฉพาะโหมด demo เท่านั้น

## 6. CMS — แก้เนื้อหาเว็บ + อนุมัติแบบสี่ตา (ประมาณ 5 นาที)

**บัญชี (รหัสผ่าน `Demo1234!` ทุกบัญชี):** ผู้แก้ไข `editor@demo.nongnooch.local` · ผู้อนุมัติ `approver@demo.nongnooch.local` · `admin@demo.nongnooch.local` มีทุกสิทธิ์แต่ก็ยังติดหลักสี่ตา (อนุมัติงานที่ตัวเองแก้ไม่ได้)

**เตรียม:** เปิด 2 หน้าต่าง — หน้าต่างปกติ login เป็น editor ที่ http://localhost:3001 และหน้าต่าง Incognito login เป็น approver (cookie ไม่ชนกัน) · อีกแท็บเปิด http://localhost:3000/th ไว้

1. (editor) เมนู **เนื้อหา** → แท็บ "สไลด์หน้าแรก" → กดแถวลำดับ 1 ("สวนสวยระดับโลก")
2. ซ้ายคือภาษาไทย (ต้นฉบับ) ขวาคือแท็บ 7 ภาษา (TH EN ZH JA KO DE FR; จุดสีทอง = มีข้อความแล้ว) → แก้ "หัวข้อ (TH)" เช่น `สวนสวยระดับโลก ต้อนรับปีใหม่` และ "หัวข้อ (EN)" เช่น `World-class Gardens: Happy New Year`
3. เล่าเรื่อง fallback: กดแท็บ **JA** → ลบช่องหัวข้อให้ว่าง (placeholder บอกว่า "ว่างไว้ = ใช้ EN") → **บันทึกร่าง**
4. กด **ดูตัวอย่าง** → แท็บใหม่เปิดเว็บจริง `http://localhost:3000/th?preview=…` มีแถบทอง "โหมดตัวอย่าง (ยังไม่เผยแพร่)" และหัวข้อใหม่ · ชี้ให้ดูว่าแท็บ http://localhost:3000/th เดิม (กด F5) ยังเป็นหัวข้อเก่า — ร่างยังไม่หลุดออกไปหน้าเว็บ
5. กด **ส่งอนุมัติ** → สถานะเป็น "รออนุมัติ" ช่องทั้งหมดถูกล็อก
6. (editor) เมนู **รออนุมัติ** → เห็นตารางก่อน/หลังรายช่อง (ขีดฆ่า = ก่อน, เขียว = หลัง) → กด **อนุมัติ** เอง → ขึ้นแถบแดง "อนุมัติไม่ได้: คุณเป็นผู้แก้ไขรายการนี้เอง … (หลักสี่ตา)"
7. (approver, หน้าต่าง Incognito) เมนู **รออนุมัติ** → ดูตารางก่อน/หลัง → กด **อนุมัติ** ("อนุมัติแล้ว เนื้อหาเผยแพร่บนเว็บไซต์ทันที")
   - ทางเลือก: กด **ไม่อนุมัติ** → ใส่เหตุผล → editor เปิดรายการเดิมจะเห็นเหตุผลสีแดง แก้แล้วส่งใหม่ได้
8. แท็บเว็บ http://localhost:3000/th กด F5 → หัวข้อใหม่ขึ้นทันที · เปลี่ยนเป็น http://localhost:3000/ja → หัวข้อเป็นภาษาอังกฤษ (fallback ไป EN เพราะ JA ว่าง) ส่วน /zh ยังเป็นภาษาจีนของเดิม
9. เมนู **Audit log** → เห็นทุกขั้น: บันทึกร่าง / ส่งอนุมัติ / อนุมัติและเผยแพร่ — ใคร (ชื่อ + role) เมื่อไร กด "ดูก่อน/หลัง" เห็นค่าที่เปลี่ยน
10. เลื่อนหน้าเว็บลงมาจะเห็น **รอบการแสดงวันนี้** (การแสดงวัฒนธรรมไทย 10:30/13:30/15:30, การแสดงช้าง 11:00/14:00) และ **คำถามที่พบบ่อย** ก่อนท้ายหน้า — มาจาก CMS เดียวกัน (แท็บ "รอบการแสดง" / "คำถามที่พบบ่อย") และแอปมือถือก็อ่าน API เดียวกัน

**ถ้าขั้นไหนล่ม (CMS):**

| อาการ | ทำอย่างนี้ |
|---|---|
| หน้าเว็บกลับไปเป็นข้อความเดิมของเว็บ / ไม่มีรอบการแสดง-FAQ | ระบบ content ล่ม เว็บใช้ข้อความสำรองในตัว → `docker compose -f deploy/compose.yaml --project-directory . restart content` แล้ว `make seed` (ไม่ลบข้อมูล) |
| แก้ไม่ได้ ช่องเป็นสีเทา "รออนุมัติอยู่" | มีคำขอค้างจากรอบซ้อม → login approver แล้ว **ไม่อนุมัติ** (ใส่เหตุผล "ซ้อม") แล้วเริ่มใหม่ |
| กด "ดูตัวอย่าง" แล้วไม่มีแท็บใหม่ (popup ถูกบล็อก) | กดลิงก์ "ลิงก์ตัวอย่าง (ใช้ได้ 30 นาที)" ข้างปุ่มแทน · ลิงก์หมดอายุใน 30 นาที (หมดแล้วเว็บแสดงเนื้อหาที่เผยแพร่ ไม่มีแถบทอง) |
| อยากคืนหัวข้อเดิม | editor แก้กลับเป็น `สวนสวยระดับโลก` / `Beautiful Garden` (JA `美しい庭園`) → ส่งอนุมัติ → approver อนุมัติ |

**ข้อมูลจำลอง (CMS):** ข้อความหน้าแรก, รอบการแสดง และ FAQ เป็นตัวอย่างจาก seed (TH+EN ครบ ภาษาอื่นบางส่วน) · ไม่มี CDN จริง หลังอนุมัติ service แค่เขียน log "cdn purge (log mode)" · เว็บดึงเนื้อหาแบบไม่แคชเพื่อให้เห็นผลทันที
