# สคริปต์ Demo: Tourist App (Flutter web)

ใช้คู่กับ [demo-script.md](demo-script.md) ส่วนนี้ใช้เวลาประมาณ 5 นาที

## เตรียมก่อนขึ้นเวที

1. เปิด Chrome ไปที่ **http://localhost:3002**
2. ทำให้เห็นเป็นจอมือถือ เลือกอย่างใดอย่างหนึ่ง:
   - กด `F12` แล้วกด `Ctrl+Shift+M` (Toggle device toolbar) เลือก "iPhone 12 Pro" หรือ "Pixel 7" แล้วกด `F5`
   - หรือไม่ต้องเปิด DevTools: บนจอกว้างแอปจะแสดงในกรอบมือถือกว้าง 420px กลางจอให้อยู่แล้ว
3. เปิดแท็บที่ 2 ไว้ที่ **http://localhost:8090** (Mock Console) สำหรับดูรหัส OTP
4. ถ้าเคย login ค้างไว้ ให้ไปที่แท็บ "เพิ่มเติม" แล้วกด "ออกจากระบบ" ก่อน

บัญชี demo: เบอร์ **0811111111** (ระบบแปลงเป็น `+66811111111` ให้เอง) มีบัตรของวันนี้อยู่แล้ว

## ถ้ามีปัญหา

| อาการ | ทำอย่างไร |
|---|---|
| หน้าขาว / ไม่โหลด | จาก worktree ของแอป: `docker compose -f deploy/compose.yaml --project-directory . up -d --no-deps app` แล้ว `Ctrl+Shift+R` |
| กด "ขอรหัส OTP" แล้วขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" | ตรวจว่า gateway ยังรันที่ http://localhost:8000 (stack หลัก) |
| กด "ขอรหัส OTP" แล้วขึ้น "เกิดข้อผิดพลาด … (rate_limited)" หรือรหัสอื่น | ขอรหัสถี่เกินไป รอ 10 วินาทีแล้วกดใหม่ |
| ไม่เห็น SMS ใน Mock Console | เปิด http://localhost:8090/sms/messages?to=%2B66811111111 ดู JSON ตรง ๆ |
| รหัสผิด / หมดอายุ | กด "เปลี่ยนเบอร์" แล้วขอรหัสใหม่ ใช้ SMS ล่าสุดเสมอ |
| ไม่มีบัตร | stack อาจยังไม่ได้ seed วันนี้ ให้ไปเล่าจากเว็บ http://localhost:3000 แทน |
| เนื้อหา Hero / FAQ มีป้าย "แสดงเนื้อหาออฟไลน์" | CMS ยังไม่ขึ้น แอปใช้เนื้อหาสำรอง เล่าต่อได้เลย เมื่อ CMS ขึ้นแล้วกด `F5` เนื้อหาจะเปลี่ยนเป็นของ CMS เอง |
| ฟอนต์ไทยดูต่างจากเว็บ | แอป demo ใช้ฟอนต์ของเครื่อง (ไม่โหลดฟอนต์จากอินเทอร์เน็ต) ไม่ต้องอธิบาย |

## ตรวจก่อนขึ้นเวที (ทีมเทคนิค)

- `make app-test` (flutter analyze + test ใน Docker) และ `make app-e2e` (login ด้วย OTP จาก mockext แล้วต้องเห็น QR อย่างน้อย 1 ใบ และแอปต้องไม่เรียก host ภายนอก)
- แอปไม่โหลดอะไรจากอินเทอร์เน็ต (ไม่มี Google Fonts / gstatic) ปิด Wi-Fi ได้ ขอแค่ stack บนเครื่องยังรันอยู่
